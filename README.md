# Radiance Cascades Compared to Unity’s Standard Global Illumination Methods

## Overview

This repository contains experimental materials for the paper *“Comparative Evaluation of Real-Time Global Illumination Methods in Unity URP”*, prepared for the DIGRA conference.

## Contents

- Raw FPS and frame-time datasets
- Figures generated for the paper
- Video recordings for visual comparison: [Watch on YouTube](https://www.youtube.com/watch?v=daDjPJyB86o&list=PLaHv1eGKS6CyZF2IG05RV7KAHvvU5-xIQ)

## Experimental Environment

- **Unity Version:** 6000.2.12f1
- **GPU:** NVIDIA RTX 4060 Laptop GPU
- **CPU:** Intel Core i7-13620H

## Reproducibility

The provided datasets and figures support the analysis and comparison of global illumination methods under the experimental setup used in this study.
